# Volumen 003 - CEO

> **Versión:** 0.1 Alpha
> **Estado:** Activo
> **Propietario:** CEO
> **Última actualización:** 2026-07-25

---

## Propósito

Este volumen define la dirección estratégica y de negocio operativa de Merchly AI, en el mismo nivel de detalle que `002-CTO` define la dirección técnica.

Mientras que `100-Organizacion/03-Roles-Ejecutivos.md` define al CEO a nivel organizacional (autoridad, alcance), este volumen define **cómo el CEO ejecuta esa responsabilidad**: modelo de negocio, criterios de éxito, estrategia comercial y métricas.

`002-CTO` responde **cómo se construye**. `003-CEO` responde **para qué se construye y cómo se sabe si funciona**.

---

## Objetivos

- Definir el modelo de negocio inicial de AICOS.
- Fijar criterios objetivos de éxito para la Fase 0 (Fundación) y condiciones de paso a Fase 1.
- Establecer una estrategia comercial preliminar, aun sin producto.
- Definir qué se mide y cómo, desde el día uno.
