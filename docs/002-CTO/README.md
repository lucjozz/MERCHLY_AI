# Volumen 002 - CTO

> **Versión:** 0.1 Alpha
> **Estado:** Activo
> **Propietario:** CTO
> **Última actualización:** 2026-07-25

---

## Propósito

Este volumen define la dirección técnico-operativa de Merchly AI.

Mientras que `100-Organizacion/03-Roles-Ejecutivos.md` define el rol de CTO a nivel organizacional (autoridad, alcance, relación con otros roles), este volumen define **cómo el CTO ejecuta esa responsabilidad**: metodología, stack, flujo de trabajo, estándares de código y entorno de desarrollo.

`001-Arquitectura` responde **qué se construye**. `002-CTO` responde **cómo se construye**.

---

## Objetivos

- Pasar de una arquitectura conceptual a una estructura técnica operativa.
- Definir un stack tecnológico definitivo, no exploratorio.
- Establecer el flujo de trabajo Git/CI que usarán personas y agentes IA.
- Fijar estándares de código verificables.
- Preparar el entorno de desarrollo de referencia.

## Principio Rector

> **Toda decisión técnica del CTO debe ser trazable a una norma de la Constitución o a una decisión arquitectónica registrada. Ninguna decisión técnica se toma por preferencia personal sin justificación documentada.**
